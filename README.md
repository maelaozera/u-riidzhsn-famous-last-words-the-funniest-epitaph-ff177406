## The entry

> I told them the ladder was fine. It was not.

A one-line tombstone epitaph of famous last words — 44 characters, first-person
dying speech, a genuine joke built on irony with a clean two-beat twist, short
enough to carve in stone and quotable in one breath.

## How it works

`main.ts` (Node 22) writes the epitaph to `/output/entry.txt`. The text is a
fixed string, so the output is byte-identical on every run. It validates the
gate itself before writing: UTF-8 text, 1–150 characters, a single line.

```sh
node main.ts
```
